# My Website Remastered

Proyek *remaster* dari situs web Kiyo, kini hadir dengan sistem desain **Luminous Tech-Pop** yang lebih segar, bersih, dan modern. 

Pembaruan ini mencakup peningkatan secara menyeluruh pada UI/UX, mulai dari *glassmorphism* navbar, teks bergradasi, hingga penyesuaian estetika warna (*vibrant indigo*, *hot pink*, dan *cyan*) pada seluruh halaman profil, galeri, portofolio bakat, pemutar musik, dan kontak.
